# Мастерская «Флёр» — доставка букетов ко Дню матери

Статический многостраничный сайт на чистых HTML, CSS и JavaScript (ES6+). Без фреймворков, без сборки и сервера: открывается двойным кликом по `index.html`.

## Страницы

| Файл | Назначение |
|---|---|
| `index.html` | Главная: hero, категории, 6 хитов, преимущества доставки |
| `catalog.html` | Каталог из 24 букетов с фильтрами по категории, цене и цвету |
| `builder.html` | Конструктор своего букета с расчётом цены |
| `delivery.html` | Калькулятор доставки, интервалы, условия, подписка для офисов |
| `care.html` | 7 правил ухода, PDF-памятка, промокод MAMA10 |
| `contacts.html` | Форма заказа, контакты, карта мастерской |
| `thanks.html` | Страница после оформления заказа |
| `privacy.html` | Политика конфиденциальности |
| `404.html` | Страница ошибки |

## Запуск

Сборка и установка зависимостей не требуются. Можно открыть `index.html` в браузере или запустить локальный статический сервер из корня проекта:

## Запуск

1. Распакуйте архив.
2. Откройте `index.html` в браузере.

Внешних зависимостей нет, кроме iframe карты Яндекса на странице контактов (загружается лениво, нужен интернет).

## Требования, которые соблюдены

- Адаптив 375 / 768 / 1280 px, без горизонтального скролла.
- Кнопки и поля не меньше 44×44 px (`--tap: 44px`).
- У всех `<img>` есть `alt`; `loading="lazy"` везде, кроме hero на главной.
- Шапка и подвал продублированы в каждом HTML без JS-шаблонов.
- Меню: бургер до 1280 px, горизонтальное с 1280 px; активный пункт подсвечивается.
- В каждой странице есть `title`, `description`, Open Graph (og:image 1200×630) и favicon.

## Аналитика (GA4 через `window.dataLayer`)

События: `view_item`, `select_item`, `catalog_filter`, `bouquet_build`, `delivery_calc`, `file_download`, `promo_copy`, `generate_lead`, `contact_click`, `cta_click`, `messenger_click`, `map_open`, `social_click`.

Любой элемент с `data-event="имя"` отправляет событие по клику; параметры берутся из атрибутов `data-event-*` (camelCase → snake_case, `value`, `price`, `quantity`, `count` — числа). Ecommerce-события (`view_item`, `select_item`, `generate_lead`) шлются из скриптов страниц; персональные данные в `dataLayer` не попадают.

Чтобы подключить GA4, добавьте стандартный сниппет Google Tag или GTM в `<head>` страниц — события уже будут в `dataLayer`.

## Как передаются данные между страницами

- Каталог и главная → заказ: `contacts.html?item_id=…&item_name=…&price=…`
- Конструктор → заказ: `item_id=CUSTOM`, `price`, `composition`
- Доставка → заказ: параметры `delivery_*`
- Заказ → «Спасибо»: `thanks.html?order=M-2026-XXXX`

Все параметры проверяются и очищаются в `form.js`.

## Что нужно сделать перед запуском

- Заменить заглушки в `img/` реальными фото (`.jpg`/`.webp`, до 300 КБ, те же имена и размеры: карточки 640×480, hero 1200×800, OG 1200×630).
- Подключить бэкенд или сервис форм: сейчас данные заказа никуда не отправляются.
- Заменить домен-заглушку `fleur-mama.example` (og:url, og:image, e-mail) на реальный и свести адреса почты к одному.
- Проверить телефон, адрес и координаты карты, добавить реквизиты оператора в `privacy.html` и показать текст юристу.
- Прогнать Lighthouse в Chrome DevTools (в среде разработки не запускался).
- При размещении в подпапке сервера проверить пути на `404.html`.
