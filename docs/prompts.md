## Запросы

### Запрос №1 — Структура сайта и общие файлы

**Текст запроса:** Роль — веб-разработчик. Статический сайт доставки букетов ко Дню матери («Флёр»). Жёсткие ограничения: только HTML, CSS, vanilla JS (ES6+), без сборки и фреймворков; тексты на русском без заглушек; адаптив 375/768/1280, без горизонтального скролла, кнопки не меньше 44×44 px; изображения .webp/.jpg до 300 КБ с alt; события GA4 в `window.dataLayer`; одинаковые шапка и подвал в каждом HTML. Шаг 1: создать `css/style.css`, `js/analytics.js`, `js/main.js` (переменные, reset, сетки, кнопки, шапка/подвал, карточки, формы, таблицы, alert, skeleton; `trackEvent`/`trackEcommerce`; подсветка пункта меню, обработчик `data-event`, бургер).

**Что получилось:** Базовый CSS на переменных (mobile-first, брейкпоинты 768 и 1280), три общих JS-файла. Обработчик `data-event` собирает параметры из атрибутов `data-event-*`, `trackEcommerce` сначала сбрасывает `ecommerce: null`.

**Что пришлось исправить вручную:** не потребовалось.

### Запрос №2 — Главная (index.html)

**Текст запроса:** Создать `index.html`: title, description 140–160 символов, Open Graph (og:image 1200×630), favicon; шапка с 8 пунктами и кнопкой «Заказать»; hero с h1 «Букеты ко Дню матери с доставкой по Москве»; 4 категории с `catalog_filter`; 6 хитов с `select_item` и `view_item` через IntersectionObserver; блок доставки; подвал с `contact_click`/`social_click`; объяснить data-атрибуты.

**Что получилось:** Полная страница. Восемь пунктов меню не помещаются при 768 px, поэтому ИИ сам перевёл меню в бургер до 1280 px (CSS и `matchMedia` в `main.js`). Первый ответ был отправлен без текстового пояснения — пояснение про data-атрибуты дано по повторному запросу.

**Что пришлось исправить вручную:** не потребовалось (исправления внёс сам ИИ, см. выше). Побочный запрос: таблица событий главной сохранена в `docs/index-analytics.xlsx`.

### Запрос №3 — Каталог (catalog.html + catalog.js)

**Текст запроса:** Каталог из 24 композиций: фильтры по категории, цене (два ползунка), цвету, сброс; карточки; пустое состояние; события `catalog_filter`, `view_item`, `select_item`; сворачиваемые фильтры на мобильных; 1/2/3 колонки.

**Что получилось:** 24 товара (b-101…b-124), фильтры, предвыбор по `?cat=`, пустое состояние с заданным текстом.

**Что пришлось исправить вручную:** не потребовалось. Ошибки ИИ найдены и исправлены им же: поле `index` в `view_item` было `null` (селектор захватывал и ссылку) — заменён на `.card[data-item-id]`; `select_item` дублировался — элементы с `data-ecommerce` теперь пропускаются в `main.js`.

### Запрос №4 — Конструктор (builder.html + builder.js)

**Что пришлось исправить вручную:** не потребовалось.
